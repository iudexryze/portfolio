The log

  1. 7 Sep 2026

    Dressing the world, and measuring whether it worked

    In flight

    Until now every surface in the game was a procedural shader stretched over primitive geometry. That was a deliberate stall — it kept the systems honest while they were being built, because nothing could hide behind good-looking art. It has stopped being useful.

    The branch replaces it. There is a MeshSet abstraction and a PlacementDressing pass, and on top of them the things a left district actually contains: industrial props, plants growing on the broken parts, standing dead, rubble, lamp heads. The storm got a real pass at the same time.

    The half I am more pleased with is the tests. It is easy to add clutter and call the level better, so the branch also adds play-mode tests that measure the result rather than trusting it — whether the horizon reads at all, whether dressing actually lands where it was asked to, what each surface costs, whether the level survey still finds a route, and whether the dread pacing curve still has the shape it is supposed to have.

    • Added MeshSet, PlacementDressing, IndustrialProps, Plants, StandingDead, RubbleMeshes, LampHeads
    • Reworked Thunderstorm, GroundDetail, StreetFacades, WallRuins, NarrativeSites
    • Tests HorizonCapture, WorldDressing, SurfaceCost, HorrorPacing, LevelSurvey, WorldSolidityDiagnostic
    • Also automated the asset-store import, and took the screenshots back out of git
    • Size 360 files, ~27,600 lines added — not merged to prod yet
  2. 2 Sep 2026

    Weather, as four systems that agree

    Merged

    Rain is not set dressing here. The protagonist builds her entire model of the world out of sound, so a constant hiss laid over everything is the most aggressive thing the world can do to her primary sense. A level in a downpour is a level where you cannot hear what is coming.

    So it had to be more than a particle system. Rain falls, the ground gets wet, the wet ground shows you where the lamps are, and the air takes the distance away — and all four move together because they read one number. The runtime debug panel reports that number, which is the only reason the four stayed in agreement while they were being tuned.

    • PR #17, #18 dynamic weather system
    • Systems Rain, RainImpacts, WeatherSurfaces, Thunderstorm, height fog, weather audio
  3. 1 Sep 2026

    A day spent stopping the interface from lying

    Ten commits in one day, all of them the same kind of bug: a readout that described the game inaccurately, or described it accurately while painting over the thing it described.

    The HUD dial and the pulse reveal were both drawing on top of what they were meant to be reporting. The stealth readout whispered its warning instead of saying it, so the label now names the state and the bar just shows it. The detection banner snapped off the instant detection ended, which read as a bug rather than relief — it now lands and bleeds off. And the camera was cutting walls open at the edge of the frame, which is a hard thing to unsee once you have seen it.

    The one I liked best: the interface is now lit by the player's own echo, so the UI belongs to the same world as everything else rather than floating above it.

    • Fixed HUD dial and pulse reveal overdraw, camera wall-clipping at frame edge
    • Changed stealth label names the state, detection banner decays, dread curve reframed
    • Lit window panes shaped rather than flat-filled; interface lit by the player's pulse

    Pulse overhaul

    Merged

  5. 22–24 Aug 2026

    The protagonist gets a skeleton

    For most of the project the MC was a single static mesh with no rig at all, which put a hard ceiling on how alive the world could feel — you cannot do contextual environmental animation with a character who cannot move. Walk cycle first, then the rest.

    • Added character rig, walk cycle, additional animation set
  6. 23 Aug 2026

    Settings, and meaning it

    Merged

    In-game resolution, fullscreen and render scale, with gamepad bindings and stick-only menu navigation underneath. The console target is far-future and has no date on it, but stick-only navigation is the kind of groundwork that is cheap now and expensive to retrofit.

    • PR #13 settings menu, gamepad bindings, stick-only UI navigation
  7. 16 Aug 2026

    Dropping Android

    The project started as a portrait Android game. It is now PC, landscape, keyboard-and-mouse or gamepad — the framing the fixed 2.5D camera actually wanted.

    The touch control layer came out entirely rather than being left half-wired to a platform nobody was building for. Half-wired code for a target you are not shipping is a liability that reads as a feature. The Android build script stayed, for whenever it comes back.

    • Removed the touch input layer; kept the Android build script and mobile render pipeline asset
  8. 12 Aug 2026

    Levels that generate themselves

    BSP partition for the space, a minimum spanning tree plus deliberate loop connections so the layout is navigable but not a corridor, archetype-driven dressing per room, and grid-rasterised walls. Loops matter more than they sound: a level made only of a spanning tree has exactly one route between any two points, which makes evading anything hunting you a matter of luck rather than reading the space.

    • Added level generator, first generated scene
  9. 10 Aug 2026

    Visual overhaul, and throwing things away

    Merged

    Two PRs that belong together: the visual pass, and then an orphaned-asset sweep behind it. Input actions cleaned up, docs cleaned up, the scene UI fixed.

    • PR #8, #10 visual overhaul, orphaned asset cleanup
  10. 4 Aug 2026

    Decoys, quests and the first words

    Merged

    The distraction system — throw something noisy, let the thing hunting you go and look at it — which is the counterweight the pulse needed. Without it, the only answer to being heard was to stop making noise, and a stealth game where the correct move is to do nothing is not a game.

    The narrative controller and the tutorial hints landed alongside it.

    • PR #6 decoys, NarrativeController, tutorial setup, scriptable objects
  11. 2 Aug 2026

    Enemies, an ending, and a CI that says no

    Merged

    Five PRs in a day. Enemy setup with the camera stack, player health, the endgame controller, the main menu, quest logs, persistent UI.

    The one that mattered longest was the least visible: branch protection rulesets, a workflow that guards merges into prod, required linear history, and a dotnet-format lint job that had to be run over the whole project once before it could start clean. Solo projects are exactly where this gets skipped, and exactly where losing an afternoon to a bad merge hurts most.

    • PR #1–#5 core mechanics, rulesets, enemy setup, distraction groundwork
  12. 27–30 Jul 2026

    First light

    Git LFS and the Unity project structure, then the design docs, then the thing itself: tap to send a pulse, watch it expand through the scene, watch whatever it touches light up and decay.

    The design documents came before the game logic on purpose. The first substantive doc was the one that writes down the trade — that sound is both how you see and how you are seen — because every system built afterwards had to answer to it.

    • Added pulse emitter, object highlighting shader, sound emitters, foot trail
    • Wrote the design docs: echolocation, stealth, enemies, level generation, narrative, visual style
