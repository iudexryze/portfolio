Game

BT-7274N

Playable now

A turn-based terminal roguelike. You type combat commands, the enemy answers, and the waves keep coming — twelve commands across attack, defence and support, all balanced against four competing resources you can never quite afford to spend.

The interesting problem was making a text interface feel like combat. Every command resolves into a readable console beat, wave modifiers change the rules rather than just the numbers, and a battery minigame runs alongside the fight so there is always a second decision competing for your attention.

Role
Solo — design, systems, code, interface, copy
Stack
Vanilla JavaScript, Canvas, no dependencies
Systems
Infinite wave scaling, four-resource economy, cooldowns, four wave modifiers, boss encounters
Build
One self-contained HTML file, ~93 KB, no build step
Note
Unofficial fan project, set in the Titanfall universe. Not affiliated with or endorsed by Respawn Entertainment or EA.

Editor tools

7 tools

Seven Unity editor windows I built to answer questions the engine will not answer for you: what is actually in this build, what is duplicated, what is broken, and what nothing references any more. All internal so far.

Validates Addressables from four angles at once: GUID and address health, hard references leaking into scenes, the same asset living in multiple groups, and addressables that end up bundled as direct prefab dependencies. Exports the whole audit as Markdown or CSV with size breakdowns.

Passes
Addressable validator, scene ref checker, duplicate finder, prefab ref checker
Output
Markdown or CSV report with per-asset size

Walks the full dependency graph and surfaces every asset with no reference from code, scenes, or other assets. Results come back filterable and sortable with file sizes, per-row accent bars for reference state, and a dismiss-filtered action. Scan results persist between sessions so a long audit survives a restart.

Method
Full AssetDatabase dependency graph
Interface
IMGUI, filterable and sortable, persistent results

Detects implicit dependency duplication across Addressable groups, and finds orphaned addresses never invoked anywhere in code by regex-scanning every .cs file. Promote to Shared moves duplicates into a shared group in one click; Purge Orphans clears dead registry entries.

Detects
Implicit duplication across groups, orphaned addresses
Fixes
Promote to shared group, purge orphan entries
Output
CSV export, per-group size breakdown

Scans every prefab and ScriptableObject for broken serialized references — missing MonoBehaviour scripts and object references pointing at deleted assets. Loads prefabs safely through PrefabUtility rather than instantiating them, catches both missing scripts and null instance ID refs, and pings straight to the asset on click.

Detects
Missing scripts, null instance ID references
Built on
SerializedProperty traversal, PrefabUtility

Parses the build report Unity writes into Editor.log after every build, then breaks asset mass down by category with proportional size bars and lists every included asset by size with type-coloured badges and percentage share. Locates Editor.log automatically on macOS, Windows and Linux.

Source
Editor.log build report, auto-located per platform
Shows
Category mass breakdown, per-asset size and share, build date

Flags every Texture2D in the project for the import mistakes that quietly cost memory: Read/Write left enabled, which doubles runtime cost; uncompressed formats; anything over 2K; and missing mipmaps on non-UI textures. Selected rows can be fixed in batch with automatic reimport.

Flags
Read/Write enabled, uncompressed format, over 2K, missing mipmaps
Fixes
Batch fix R/W and compress, with auto-reimport

Pick any asset and see both directions at once: everything it pulls in, and everything that pulls it in, side by side. Direct dependencies sit at full opacity and indirect ones drop back. Double-click any row to drill into that asset's own web, with a recursive/direct toggle and independent search per panel.

Shows
Forward and reverse dependencies, direct vs indirect
Navigation
Double-click to drill in, per-panel search, recursive toggle

About

I am a game developer and technical artist in Bangalore, currently at Gameberry Labs building games at scale. Before that I was at ZVKY Design Studio, where I shipped two commercial slot games solo — gameplay systems, shader graphs, and the whole delivery pipeline.

The work I care about sits between code and craft. In practice that means writing C# during the day and sculpting environments in Blender at night, and it means that when a project stalls on something unglamorous — a build that got too big, a dependency graph nobody can read — I tend to go build the tool that answers it. That is where the seven editor windows above came from.

Right now most of my own time goes into Project Phantom Parry, an eldritch horror game where I own the story, the design, the code and the sound.
